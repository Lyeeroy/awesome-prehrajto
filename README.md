## Installation
1. Install the [Tampermonkey extension for Firefox](https://addons.mozilla.org/en-US/firefox/addon/tampermonkey/).
2. Copy the raw content of the [GitHub-link](https://raw.githubusercontent.com/Lyeeroy/free-prehrajto/refs/heads/main/GitHub-link) file.
3. Open Tampermonkey, create a new script, paste the content, and save (Ctrl+S).
